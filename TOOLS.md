# 🔧 TOOLS.md — Справочник инструментов

Все инструменты исполняются на стороне `mcp_forge_server.py`.  
Хост передаёт запрос → LLM выбирает инструмент → сервер исполняет → результат возвращается в диалог.

---

## Инструменты

### 📧 send_email — Отправка письма

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `to_email` | string | ✅ | Email получателя |
| `subject` | string | ✅ | Тема письма |
| `body` | string | ✅ | Текст письма |
| `is_html` | boolean | — | `true`, если body содержит HTML (по умолч. `false`) |
| `attachments` | array | — | Вложения: `[{"filename": "doc.pdf", "content": "<base64>"}]` |

Настройки в `.env`: `EMAIL_ADDRESS`, `EMAIL_PASSWORD`, `SMTP_SERVER`, `SMTP_PORT`

Максимальный размер одного вложения: 25 МБ. Максимум получателей: 100.  
Таймаут операции увеличен до 60 с для больших вложений.

---

### 🔍 search_web — Поиск DuckDuckGo

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `query` | string | ✅ | Поисковый запрос |
| `max_results` | integer | — | 1–10, по умолч. из `DDG_MAX_RESULTS` |
| `region` | string | — | `wt-wt` (везде), `ru-ru`, `us-en`, `de-de` |
| `timelimit` | string | — | `d` = день, `w` = неделя, `m` = месяц, `y` = год |

Работает без API-ключа. Настройки в `.env`: `DDG_MAX_RESULTS`, `DDG_REGION`.

---

### 📰 get_news — Новости DuckDuckGo

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `query` | string | ✅ | Тема новостей |
| `max_results` | integer | — | 1–10, по умолч. из `DDG_MAX_RESULTS` |
| `region` | string | — | `ru-ru`, `wt-wt`, `us-en` |

Использует метод `ddgs.news()` — в отличие от `search_web` возвращает дату публикации и источник.

---

### 🌤 get_weather — Текущая погода

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `city` | string | ✅ | Название города (на любом языке) |
| `units` | string | — | `celsius` (по умолч.) или `fahrenheit` |

Источник: [open-meteo.com](https://open-meteo.com/) — бесплатно, без API-ключа.  
Возвращает: температуру, ощущаемую температуру, влажность, скорость ветра, осадки, описание погоды.

---

### 🕐 get_time — Текущее время и дата

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `city` | string | — | Название города |
| `timezone` | string | — | IANA-таймзона (`Europe/Moscow`, `Asia/Tokyo`) |

Если параметры не указаны — возвращает серверное время.  
Параметры `city` и `timezone` взаимозаменяемы; при указании обоих приоритет у `timezone`.

Встроенная таблица городов включает: Москва, Санкт-Петербург, Киев, Минск, Алматы, Ташкент,
Берлин, Лондон, Париж, Нью-Йорк, Токио, Пекин, Дубай, Сидней, Новосибирск, Владивосток,
Екатеринбург и другие.

---

### 💱 get_exchange_rate — Курсы валют

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `base_currency` | string | ✅ | Базовая валюта: `USD`, `EUR`, `RUB`, `KZT` и др. |

Источник: [open.er-api.com](https://open.er-api.com/) — бесплатный уровень, без ключа.  
Возвращает курсы относительно базовой валюты. Данные обновляются раз в сутки.

---

### 🌐 fetch_url — Загрузка веб-страницы

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `url` | string | ✅ | Полный URL (начиная с `https://`) |
| `max_chars` | integer | — | Лимит символов, по умолч. из `FETCH_MAX_CHARS` |

Извлекает текст через BeautifulSoup + lxml. Удаляет скрипты, стили, рекламу, навигацию, footer.  
Не поддерживает страницы с авторизацией и JavaScript-рендерингом.

---

### 🔐 generate_password — Генератор паролей

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `length` | integer | — | Длина, по умолч. из `PWD_DEFAULT_LEN` (16) |
| `symbols` | boolean | — | Включить спецсимволы, по умолч. из `PWD_DEFAULT_SYMBOLS` |
| `count` | integer | — | Количество паролей (1–10) |

Использует `secrets.choice()` — криптографически стойкий генератор.

---

### 📷 generate_qr — QR-код

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `text` | string | ✅ | Текст или URL для кодирования |
| `box_size` | integer | — | Размер ячейки в пикселях (по умолч. 10) |
| `border` | integer | — | Толщина рамки в ячейках (по умолч. 4) |

Возвращает строку вида `QR_PNG_BASE64:...` — GUI отображает как изображение автоматически.

## Графический интерфейс (GUI)

Запускается командой «открой GUI» или напрямую:

```bash
python gradio_forge_gui.py
# Открыть в браузере: http://127.0.0.1:7860
```

### Вкладки GUI

| Вкладка | Инструмент | Особенности |
|---|---|---|
| 📧 Email | `send_email` | Поддержка вложений, HTML-режим |
| 🔍 Поиск | `search_web` | Выбор региона и временного периода |
| 📰 Новости | `get_news` | Дата публикации и источник |
| 🌤 Погода | `get_weather` | Цельсий / Фаренгейт |
| 🕐 Время | `get_time` | Город или IANA-таймзона |
| 💱 Валюты | `get_exchange_rate` | Произвольная базовая валюта |
| 🌐 Страница | `fetch_url` | Лимит символов |
| 🔐 Пароль | `generate_password` | Длина, символы, количество |
| 📷 QR-код | `generate_qr` | Отображение изображения |
| 📋 Буфер | `clipboard_read` / `clipboard_write` | Чтение и запись |

Кнопка **«🔴 Завершить сеанс»** в правом нижнем углу останавливает Gradio и закрывает вкладку.

## Добавление нового инструмента

### 1. Зарегистрировать в `mcp_forge_server.py`

```python
"my_tool": {
    "name": "my_tool",
    "description": "Краткое описание — модель читает это при выборе инструмента",
    "inputSchema": {
        "type": "object",
        "properties": {
            "param1": {"type": "string", "description": "Описание параметра"},
        },
        "required": ["param1"],
    },
},
```

### 2. Добавить обработчик в `MCPForgeServer`

```python
async def _tool_my_tool(self, args: dict) -> str:
    param1 = args.get("param1", "")
    # логика инструмента
    return f"✅ Результат: {param1}"
```

Диспатч автоматический — сервер ищет метод `_tool_{name}` по имени инструмента.

### 3. Добавить описание в `mcp_forge_host.py`

Добавить запись в список `TOOLS` хоста, чтобы LLM знала об инструменте при function calling.

### 4. Добавить вкладку в `gradio_forge_gui.py`

```python
with gr.Tab("🔧 My Tool"):
    param1_input = gr.Textbox(label="Параметр 1")
    run_btn = gr.Button("Выполнить")
    output = gr.Textbox(label="Результат")
    run_btn.click(fn=call_my_tool, inputs=[param1_input], outputs=[output])
```
